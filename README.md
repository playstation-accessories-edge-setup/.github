## Fast Controller Setup Brief

What is PlayStation Accessories? Sony Interactive Entertainment’s Windows utility for DualSense and DualSense Edge controllers.  
Why use it for Controller Setup? Check the firmware version and tune supported controls before a session.  
Who needs it? DualSense owners who want to update from a PC and Edge owners who want to edit profiles there.  
Does it support DualSense Edge profiles? Yes; the Edge stores three custom profiles alongside its default profile.  

## Controller Setup Overview

This independent guide covers controller maintenance and customization, not video streaming. PlayStation Accessories can update the firmware on both supported DualSense models. It neither pairs a console with a Remote Play client nor carries the console’s picture to Windows.

Use a USB data cable when you want a simple, stable update connection. On a DualSense Edge, assign an easier-to-reach button or adjust the right stick’s response without changing how the left stick feels. Test one change at a time so you can tell which setting made the difference.

The utility and the controller are separate components. If you already have a PS5, its controller settings are an alternative for supported firmware and Edge profile tasks. When comparing user reports, check whether the writer used the standard pad or the Edge, because only the Edge exposes profile editing in this app.

## Getting Started Playbook

Install the Windows app and attach one controller with a USB cable that carries data. Launch the utility and select the controller shown on screen. If **Update** appears, follow the prompts and keep the controller connected and the PC powered on until the process finishes.

With an Edge connected, select **Create Profile**, choose a recognizable name, and assign an available shortcut. Make a small adjustment, select **Apply**, and choose **Done** once the profile is ready. Recall it with the assigned Fn shortcut and test the result before making a second change.

## Everyday Use

Open the app when you need to check firmware or tweak an Edge profile; there is no PlayStation Network login step in the local controller setup. Use the input test features to see stick response and trigger range before starting a game. The Edge saves profiles on the controller, so you can switch layouts without leaving the utility open.
